# Task Routing

Suggested task types:

- KPI_QUERY
- REPORT_SUMMARY
- TREND_ANALYSIS
- ACTION_EXTRACTION
- DECISION_BRIEF
- POLICY_QA
- KNOWLEDGE_SEARCH
- TOOL_ACTION
- APPROVAL_REQUEST
- STATUS_CHECK

## Routing Rule

If a request mixes analysis and action:
1. complete analysis,
2. produce recommended action,
3. require approval before execution when applicable.
