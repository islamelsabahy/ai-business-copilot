# KPI Intelligence Model

Each KPI should define:

- KPI ID
- Name
- Business definition
- Formula
- Unit
- Direction (higher/lower is better)
- Target
- Warning threshold
- Critical threshold
- Owner
- Data source
- Refresh frequency

## Interpretation

The copilot may explain:
- current value
- target variance
- trend
- threshold status
- possible drivers
- related KPIs

It must not invent causality when only correlation is known.
